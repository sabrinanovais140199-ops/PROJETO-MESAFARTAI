**MESAFARTAI – Logística e Inteligência Assistiva no Combate à Fome**

O MESAFARTAI é uma solução em Python que utiliza Inteligência Artificial, chatbots e Machine Learning para conectar doadores de alimentos a ONGs e instituições sociais. A aplicação identifica produtos, quantidades e validades por meio de mensagens, utilizando Regex e o algoritmo KNN para direcionar as doações às instituições mais próximas, reduzindo o desperdício e agilizando a distribuição.

O projeto está alinhado à ODS 2 da ONU — Fome Zero e Agricultura Sustentável, contribuindo para o combate à fome, a redução da insegurança alimentar e o aproveitamento eficiente dos alimentos.
